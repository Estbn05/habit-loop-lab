# Product Brief

## Problem

Most habit trackers over-focus on visible completion, streak pressure, and customization. That creates a planning loop where the user feels productive without lowering the friction of action.

Habit Loop Lab is designed around a different thesis: a useful tracker should help a behavior move from conscious goal pursuit to automatic context-triggered execution.

## Product Principles

1. Identity before outcome.
   Users do not only track a task; they cast evidence for a desired identity.

2. Craving before response.
   The app highlights the anticipated state change before the user logs the action.

3. Standardize before optimizing.
   Every habit starts as a two-minute behavior attached to an existing anchor.

4. Recovery before analysis.
   A lapse is treated as learning data. The next action is a minimum viable repair.

5. Automaticity before gamification.
   Progress is measured through ease, consistency, habit age, and reminder fading.

## Core User Flow

1. User completes readiness and confidence rulers.
2. App identifies the user's stage of change.
3. User defines an identity statement.
4. User creates one if-then habit plan.
5. User sees the daily cue, craving, response, and reward loop.
6. User emits a micro-vote or records a lapse.
7. App adapts feedback, automaticity, relapse support, and reminders.
