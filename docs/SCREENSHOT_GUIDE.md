# Screenshot Guide

Use these screenshots in the GitHub README after publishing the first version.

## Suggested Screenshots

1. Onboarding diagnosis
   Show readiness rulers, identity statement, change talk, and first if-then plan.

2. Daily habit loop
   Show the cue, craving, response, reward loop and the micro-vote button.

3. Habit stacking map
   Show multiple habits linked from current routines to tiny actions.

4. Relapse re-framer
   Record a missed day, then show the "never miss twice" recovery panel.

5. Automaticity transition
   Show the 0-21, 21-66, and 66-335 day transition panel.

## How To Capture

1. Start the app:

```bash
npm run start
```

2. Open:

```text
http://127.0.0.1:5173
```

3. Use your browser screenshot tool.

4. Save images in:

```text
docs/screenshots/
```

Recommended names:

```text
onboarding.png
daily-loop.png
habit-stacking.png
relapse-reframer.png
automaticity.png
```

5. Uncomment or add the image section in `README.md`.
